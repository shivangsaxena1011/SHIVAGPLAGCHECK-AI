## Written From Scratch

The following core components were designed and authored specifically for SHIVANG PLAGCHECK AI:
1. **Frontend Architecture**: Modern Next.js 14+ React dashboard, interactive split-view report viewer, dynamic color palette generator, source highlight syncing, AI analysis sentence explorer, and responsive controls.
2. **Unified Match Evidence Schema**: Universal JSON structure bridging exact, semantic, AI, and citation findings with exact character, sentence, paragraph, and page coordinate mappings.
3. **Deterministic Score Fusion Engine**: Rigorous union interval coverage algorithms that compute exact coverage, near-verbatim coverage, and semantic coverage without double-counting, alongside customizable quote/bibliography exclusions.
4. **Document Processing Engine**: Multi-format document parser (PDF, DOCX, TXT) with character-to-page-and-sentence coordinate mapping.
5. **Reporting System**: Professional PDF generator mirroring high-density academic originality reports, complete with score cards, source breakdown tables, highlighted document pages, and methodology disclosures; plus standalone HTML exporter.
6. **Unified API**: FastAPI application with background asynchronous job execution, real-time progress tracking ($0\% \rightarrow 100\%$), SQLite / PostgreSQL persistence with pgvector support, and JWT security.
7. **CLI Tooling**: `python -m originalguard` command-line utility for desktop analysis, corpus management, and PDF report export.
8. **Test Suite**: Automated unit and end-to-end tests for all detectors, pipelines, and APIs.
